### 1. Schema — `db/migration/V2__create_book.sql`
`book(id identity PK, isbn varchar(13) NOT NULL UNIQUE, title varchar(200) NOT NULL, author varchar(150) NOT NULL, category varchar(50), published_year int, total_copies int NOT NULL, available_copies int NOT NULL, version bigint NOT NULL DEFAULT 0, CHECK (total_copies >= 0), CHECK (available_copies >= 0 AND available_copies <= total_copies))` + index on `lower(title)`/`lower(author)` skipped (YAGNI at this scale).

### 2. Entity — `entity/Book.java`
Lombok `@Getter`, protected no-arg ctor, `@Version Long version`. Domain methods keep rules in one place:
- `Book(isbn, title, author, category, publishedYear, totalCopies)` → `available = total`
- `updateDetails(title, author, category, publishedYear)`
- `changeTotalCopies(newTotal)`: `onLoan = total - available`; if `newTotal < onLoan` → `BusinessRuleException("COPIES_ON_LOAN", ...)`; else `available = newTotal - onLoan`
- `hasCopiesOnLoan()`
(borrow/return methods come with the loans PR.)

### 3. Repository — `repository/BookRepository.java`
`JpaRepository<Book, Long>, JpaSpecificationExecutor<Book>`, `boolean existsByIsbn(String)`, `boolean existsByIsbnAndIdNot(String, Long)`.
`repository/BookSpecifications.java`: `matchesQuery(q)` (lower title/author like `%q%` OR isbn = normalised q), `hasCategory(c)` (case-insensitive equals), `isAvailable()` (`availableCopies > 0`); each returns `null` for blank input so they compose with `Specification.allOf(...)`. Specifications avoid the PostgreSQL "could not determine data type" problem of nullable JPQL params.

### 4. DTOs — `dto/BookRequest.java`, `dto/BookResponse.java`
- `BookRequest(@NotBlank @Pattern(ISBN-10/13 after stripping '-'/' ') isbn, @NotBlank @Size(max=200) title, @NotBlank @Size(max=150) author, @Size(max=50) category, @Min(1450) @Max(2100) Integer publishedYear, @NotNull @Min(0) @Max(1000) Integer totalCopies)`
- `BookResponse(id, isbn, title, author, category, publishedYear, totalCopies, availableCopies)` + `static from(Book)`

### 5. Service — `service/BookService.java`
`@Transactional` on writes, `readOnly` on reads. ISBN normalised (strip hyphens/spaces, uppercase X).
- `search(q, category, available, Pageable)` → `PageResponse<BookResponse>`
- `get(id)` → 404 `"Book {id} not found"`
- `create(req)` → duplicate ISBN → 409 `DUPLICATE`
- `update(id, req)` → duplicate ISBN on another book → 409 `DUPLICATE`; `changeTotalCopies` rule
- `delete(id)` → `hasCopiesOnLoan()` → 409 `HAS_ACTIVE_LOANS`

### 6. Controller — `controller/BookController.java`
`/api/books`: `GET` (params `q`, `category`, `available`, `@PageableDefault(size = 20, sort = "title")`), `GET /{id}`, `POST` → 201 + `Location`, `PUT /{id}`, `DELETE /{id}` → 204.

### 7. Paging safety (small, shared)
- `application.yml`: `spring.data.web.pageable.max-page-size: 100`
- `GlobalExceptionHandler`: `PropertyReferenceException` (bad `sort=` field) → 400 `BAD_REQUEST` instead of 500, with a test in `GlobalExceptionHandlerTest`.
